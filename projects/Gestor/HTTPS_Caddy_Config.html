Configuração HTTPS com Caddy + DuckDNS

Documento gerado em: 27/08/2026

1. Situação Atual

Servidor: IP Fixo 192.168.0.111
Domínio: mjtsystems-gestor.duckdns.org
Certificado: Obtido via DNS-01 (Let's Encrypt + DuckDNS)
Acesso externo atual: http://mjtsystems-gestor.duckdns.org:3001

Arquitetura Atual

Internet → Roteador (portas 3001/9000) → 192.168.0.111:3001 → Express (HTTP)

Portas Encaminhadas no Roteador

Porta Externa Protocolo IP de Destino Porta Interna
3001 TCP 192.168.0.111 3001
9000 TCP 192.168.0.111 9000

2. O que foi feito até agora

✓ Caddy compilado com plugin DuckDNS
O módulo dns.providers.duckdns foi adicionado ao Caddy para permitir validação DNS-01.
✓ Certificado TLS obtido com sucesso
O Let's Encrypt emitiu o certificado para mjtsystems-gestor.duckdns.org via desafio DNS-01.

Caddyfile Configurado

{
    http_port 80
    https_port 443
}

mjtsystems-gestor.duckdns.org {
    tls {
        dns duckdns 9fc5de1c-89ef-4a25-add9-a8934f27402b
    }
    reverse_proxy localhost:3001
}

3. Problema Identificado

⚠ HTTPS não funciona externamente porque:

O Caddy escuta na porta 443, mas o roteador só encaminha as portas 3001 e 9000.
O tráfego externo na porta 443 nunca chega ao Caddy.

4. Soluções Possíveis

Opção 1: Encaminhar porta 443 no roteador (RECOMENDADO)

Vantagens:
  • Não altera nada para quem já usa o sistema
  • URL continua a mesma, só muda http → https
  • Sem risco de quebra para empresas clientes

Ação necessária: Solicitar ao administrador do roteador para adicionar:

Porta Externa Protocolo IP de Destino Porta Interna
443 TCP 192.168.0.111 443

Opção 2: Rodar Caddy na porta 3001

Impactos:
  • Todos os usuários precisam atualizar de http:// para https://
  • Apps mobile precisam de atualização com nova URL
  • Risco de quebra se alguém não atualizar
  • Porta do Express precisa mudar (ex: 3002)

URL mudaria de:

  • Antes: http://mjtsystems-gestor.duckdns.org:3001
  • Depois: https://mjtsystems-gestor.duckdns.org:3001

5. Fluxo dos Dados

Com Opção 1 (Porta 443)

Internet → Roteador (:443) → Caddy (HTTPS:443) → Express (:3001) → Go Backend (:9000)

Com Opção 2 (Porta 3001)

Internet → Roteador (:3001) → Caddy (HTTPS:3001) → Express (:3002) → Go Backend (:9000)

7. Comandos Úteis

# Iniciar Caddy
C:\Caddy\caddy.exe start --config C:\Caddy\Caddyfile

# Parar Caddy
C:\Caddy\caddy.exe stop

# Verificar módulos instalados
C:\Caddy\caddy.exe list-modules

# Verificar logs
C:\Caddy\caddy.exe version

8. Recomendação

Recomendação: Solicitar encaminhamento da porta 443

Esta é a opção mais segura para manter a continuidade do sistema para as empresas que já estão usando.
Não há necessidade de alterar URLs ou atualizar aplicativos mobile.

9. Checklist para Solicitação ao Administrador do Roteador

  • ☐ Solicitar encaminhamento da porta 443 (TCP) para 192.168.0.111
  • ☐ Confirmar se porta 443 está disponível (não bloqueada por ISP)
  • ☐ Testar acesso externo após configuração: https://mjtsystems-gestor.duckdns.org
  • ☐ Verificar se firewall do Windows permite tráfego na porta 443

10. Troubleshooting

Se HTTPS não funcionar após encaminhar porta 443:

  1. Verificar se o firewall do Windows permite conexões nas portas 80 e 443:
netsh advfirewall firewall add rule name="Caddy HTTP" dir=in action=allow protocol=TCP localport=80
netsh advfirewall firewall add rule name="Caddy HTTPS" dir=in action=allow protocol=TCP localport=443
  1. Reiniciar o Caddy:
C:\Caddy\caddy.exe stop
C:\Caddy\caddy.exe start --config C:\Caddy\Caddyfile
  1. Verificar se o certificado foi emitido:
C:\Caddy\caddy.exe list-modules
